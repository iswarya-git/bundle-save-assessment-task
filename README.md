
# Bundle & Save UI Component

This is a responsive HTML/CSS component showcasing a "Bundle & Save" offer. It allows users to select product bundles with dynamic pricing, discounts, and styling.

## ✨ Features

- Multiple bundle options (1, 2, or 3 pairs)
- Dropdowns for size and color per item
- Visual discounts (e.g., 50% OFF, Most Popular)
- Free shipping message
- Total price display
- "Add to Cart" button with a plus icon
- Uses Inter font and Font Awesome icons
